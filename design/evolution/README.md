# Evolution paths

These paths and sprites ship in lilgotchi 1.0.0. The preview reads the same artwork modules as the live game. Each type covers the original evolution branches while retaining its own appearance.

Each new pet type covers all 12 original identities: egg, baby, child, two teens, six adults and the special elder. Pet types never cross into each other. Care selects a branch inside the same type.

| Original adult | Slice | Cypunk | Lilgotchi |
| --- | --- | --- | --- |

The original egg hatches after 90 seconds. Baby becomes child. At the child evolution check, at most one care mistake leads to Tamatchi. More mistakes lead to Kuchitamatchi. Adult checks use accumulated care mistakes and discipline in the order shown in each document.

Only Maskutchi has the special elder route. Alive, age 10 or older and full discipline makes the pet eligible, with a 5% chance each simulation tick. This is the same route used by the existing cracked egg, spoiled pizza and glitch elder. It is not a neglect outcome or a guaranteed birthday change.

Read the complete paths and art notes for [Slice](slice.md), [Cypunk](cypunk.md) and [Lilgotchi](lilgotchi.md). These reflect the current engine, not a newly verified claim about original hardware.

Each type has 68 frames: two egg poses and six expressions for each of the 11 hatched forms. All frames fit a 12 by 12 grid. The preview adds a one pixel margin around that grid so the largest eggs remain fully visible.
